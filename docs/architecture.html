Factory Inventory Management System — Architecture

A demo full-stack dashboard: Vue 3 single-page application served by Vite, talking to a read-only FastAPI service that filters in-memory mock data loaded from JSON files. No database, no persistence.

Vue 3 + Composition API Vite 5 Axios FastAPI Pydantic Uvicorn In-memory JSON data pytest

System Architecture

Three tiers in two processes: the Vite dev server delivers the SPA, the SPA calls the FastAPI service over HTTP, and the service answers from Python lists hydrated from JSON files at startup.

Data Flow

Example: the user changes the Warehouse filter while viewing the Dashboard.

FilterBar select changes

v-model writes the new value into the shared useFilters composable (module-level singleton refs for the 4 global filters).

View reacts

Each routed view watches the filter refs; the Dashboard's watcher calls loadData().

api.js builds the request

getCurrentFilters() maps the selections to {warehouse, category, status, month}; api.js appends only non-"all" values as query params and issues Axios GETs to http://localhost:8001/api/....

FastAPI filters in memory

The endpoint runs apply_filters() and filter_by_month() over the lists loaded by mock_data.py — plain list comprehensions, no database queries.

Pydantic validates and serializes

Results are validated against the response models and returned as JSON.

Refs update, computeds derive, UI re-renders

Raw responses land in refs (allOrders, inventoryItems, summary); computed properties derive KPIs and chart series; SVG charts and tables re-render automatically.

Frontend Structure

Page-level views, reusable components, and shared-state composables under client/src/. Global styles and the navigation shell live in App.vue.

Views — src/views/

  • Dashboard — KPI cards, order-health donut, revenue vs. $800K/month goal, low stock and backlog tables
  • Inventory — stock table with warehouse / category filtering and item detail modal
  • Orders — order list with status filtering
  • Spending — spend summary, monthly bars, category breakdown, transactions
  • Demand — demand forecast trends joined with inventory
  • Reports — quarterly performance and monthly trend charts
  • Backlog — exists but is not wired into the route map

Components — src/components/

  • FilterBar — the 4 global filter selects
  • InventoryDetailModal / ProductDetailModal / BacklogDetailModal / CostDetailModal — drill-down popups
  • TasksModal — task list (mock + API-backed)
  • ProfileMenu / ProfileDetailsModal — mock user menu
  • LanguageSwitcher — English / Japanese toggle

Composables — src/composables/

  • useFilters — singleton refs for the 4 global filters shared by all views
  • useRouter — minimal History-API router (path ref, navigate, popstate)
  • useI18n — EN/JA dictionaries, currency switching (USD / JPY at a fixed rate)
  • useAuth — hardcoded demo user, mock logout and tasks

Notes & Known Gaps

Useful context when reading or extending the code.

  • Demo constants: revenue goal is $800K per month ($9.6M when all months are selected); other KPI targets (fulfilled orders, fill rate) are hardcoded in Dashboard.vue.
  • Data resets on backend restart — everything lives in memory; generate_data.py rebuilds the JSON sample set.
  • Routing was migrated from vue-router to the in-house useRouter composable (the internal package registry does not serve vue-router); behavior is unchanged for the six static routes.
  • Reports.vue bypasses api.js (direct Axios calls with hardcoded URLs) and ignores the global filters.
  • Auth and the user profile are mock-only; CORS is wide open — fine for a demo, not for production.
  • The client calls /api/tasks (and TasksModal supports add/delete/toggle), but the backend implements no tasks endpoints — a console error is logged on every page load.
  • Dashboard.vue references a PurchaseOrderModal component that does not exist, and api.js targets /api/purchase-orders endpoints the backend never defines (only unused Pydantic models and an empty JSON file exist).
  • Backlog.vue is a complete view that is reachable from no route or nav tab.
